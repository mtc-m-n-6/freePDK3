# AI向け文脈（AIへの依頼の冒頭に貼る）

## プロジェクトの目的
- FreePDK3のLayerMapとデザインルールから、KLayoutのDRC（Ruby）を生成するPythonコマンドを作る。
- 動くものを作るだけでなく、品質（読みやすさ・エラー処理・テスト）の判断力を身につけることが目的。

## 環境
- OS：Windows／エディタ：VS Code／Python：[3.15.2]／KLayout：[0.30.12]／テスト：pytest
- 長さの単位はnm。KLayoutは数値のみだとμmとして扱うため、`.nm`を付ける。

## AIへの依頼のルール
1. 不確かな点は「不確か」と明記する。KLayoutのコマンド・APIは、確信がなければ推測で書かない。
2. 依頼の冒頭に、作業モードを書く。
   - 学習：答えやコードは出さず、問題点・理由・ヒントだけを出す。
   - 納品：仕様とテストは私が書く。コードの下書きを書く。
3. レビューを頼んだ時は、修正コードを出さず、「問題点／理由／重要度」の表で答える。
4. Rubyのコードを出す時は、使ったコマンドごとに、公式マニュアルのどの項目に対応するかを示す。
