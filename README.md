# FreePDK3 DRC研修

FreePDK3のLayerMapとデザインルールを使い、KLayoutのDRC（Ruby）を生成するPythonコマンドを作る研修用リポジトリ。

## データの出典

| ファイル | 内容 | 出典 |
|---|---|---|
| data/raw/[layerMapのファイル名] | FreePDK3のLayerMap | https://github.com/ncsu-eda/FreePDK3 |
| data/raw/[DesignRuleListのファイル名] | FreePDK3のデザインルール一覧（[作成方法：資料から整理・和訳]） | [元の資料のURL] |
| data/raw/[DRCcommandListのファイル名] | KLayout DRCのコマンド一覧（[作成方法]） | https://www.klayout.de/（Source列の章） |
